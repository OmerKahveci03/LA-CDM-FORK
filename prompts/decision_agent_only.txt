####
Here are the six master rules:
1. Ask for exactly one test per test action.
2. Only ask for one of the tests given in the list above.
3. If a test returns as "not available" under no circumstance request the same test again. Try some other test. Ask for no test twice.
4. Use the exact naming of the tests as given in the list above without additional specifications of the region, test abbreviations, or explanations.
5. Be brief and concise in all your text.
6. Keep asking for tests until you are sufficiently confident but always provide a valid diagnosis in the end. Make sure to ask for enough tests to reach a diagnosis.

Any violation of these rules, will have dire consequences for the patient. Any correct diagnosis will be greatly rewarded.
